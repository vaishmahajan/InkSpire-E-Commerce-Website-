🛒 Inkspire – Smart Stationery E-Commerce Platform

Inkspire is a full-stack e-commerce web application designed to simplify and personalize stationery shopping.
It provides users with an intuitive and responsive interface, same-day delivery options, tailored bundles, and efficient product management powered by a robust backend.

🚀 Features :-

🖥️ Responsive UI: Built with Angular, HTML, CSS, and Bootstrap for smooth navigation across devices.

⚙️ RESTful APIs: Developed using Java and Spring Boot for seamless frontend-backend communication.

🧾 Product Management: Add, update, and organize stationery items efficiently.

🔍 Smart Search & Filtering: Enhanced search experience with dynamic filters and quick results.

📦 Automated Inventory Handling: Real-time updates for product availability and stock control.

🎯 Personalized Shopping Experience: Custom bundles and offers based on user needs.

🧠 Tech Stack :-

Frontend: Angular, HTML, CSS, Bootstrap
Backend: Java, Spring Boot
Database: MySQL
Tools & IDEs: IntelliJ IDEA / VS Code, Postman, GitHub
